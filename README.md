# GF2Recorder｜少前2任务助手（前台模式）

适用于《少女前线2：追放》官方 Windows 客户端的点击、滑动和滚轮录制回放工具。程序按进程 `GF2_Exilium.exe` 定位游戏，以 1920×1080 游戏客户区作为统一坐标，不通过 ADB。

## 使用

1. 将《少女前线2》PC客户端设置为窗口模式、1920×1080。
2. 启动游戏并进入主界面，再启动本程序。
   程序会自动请求管理员权限，以便读取游戏画面并录制游戏内输入。
3. 先点击“测试PC连接”，检查预览是不是当前游戏画面。
4. 按 Ctrl+Alt+F8 开始录制，在游戏窗口内完成一次流程，按 Ctrl+Alt+F9 停止。
5. 设置循环次数，点击“启动前台任务”；Ctrl+Alt+F10 可随时紧急停止。
6. 第一次迁移后建议开启调试模式逐步检查坐标，并用无消耗步骤确认点击、滑动和滚轮生效。

## 前台运行

- 启动任务后，程序会恢复并切换到游戏窗口，使用真实 Windows 鼠标输入执行点击、滑动和滚轮，以兼容不接受后台窗口消息的游戏客户端。
- 任务运行期间会移动并占用实体鼠标，请勿操作电脑；可随时按 Ctrl+Alt+F10 紧急停止。
- 任务正常结束、停止或失败后，程序会尽量恢复启动前的鼠标位置和前台窗口；如果游戏原来处于最小化状态，也会重新最小化。
- 滚轮步骤支持右键修改格数，例如把录制的 1 格改成 10 格；回放会逐格发送滚轮事件，确保不同格数产生实际差异。

## 智能确认、状态校正与调试

- 点击步骤可设置智能确认：识别区域出现后再执行点击，也可按间隔重试前一个触发步骤。
- 点击步骤可设置双状态校正：目标状态直接确认，需校正状态先切换再确认。
- 调试模式每执行一步暂停并显示临时截图、点击位置、鼠标坐标和识别结果。
- 每一步支持修改等待时间、坐标、备注及删除。
- 右键任意步骤可选择“复制这步操作”，副本会紧接着插入原步骤下方，并完整保留等待时间、坐标、备注和智能识别设置。
- 支持录制并回放鼠标滚轮，步骤列表会显示滚动方向和格数。
- 右键滚轮步骤可选择“修改滚轮格数”，例如将录制的 1 格调整为 10 格。

## 旧数据迁移

新版数据保存在 `%LocalAppData%\GF2Recorder`。首次启动且新目录为空时，程序会从 `%LocalAppData%\LDRecorder` 复制任务、备注和识别模板，并保留旧目录作为备份。

## 安全提示

程序不会注入游戏、修改游戏数据或绕过保护机制。界面更新、网络延迟和窗口焦点变化都可能影响结果；自动操作也可能受到游戏服务条款限制，请自行评估并先用无消耗流程验证。

## 发布

安装 .NET 8 SDK 后，在项目目录执行：

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

每次向 `main` 分支提交代码，GitHub Actions 都会在 Windows 环境自动还原依赖、编译并发布自包含单文件程序；成品直接发布到 Releases，不占用 Actions Artifact 配额，文件名为 `GF2Recorder-v版本号.exe`，同时附带 SHA-256 校验文件。也可以在 Actions 页面手动运行该流程。
